# Calculator-Cortex-M-or-many-microcontrollers
A Calculator that Can calculate basic not Advanced for every micro controllers like Cortex m Pico Arduino Generic QEMU and many more
# FaqS:
How to Install it?
#ans:
to install you will need dependency for linux its:
1. gcc-avr binutils-avr avr-libc (for Arduino)
2. gcc-arm-none-eabi binutils-arm-none-eabi-binutils (for Pico Generic QEMU)"
# most dangerous part ⚠️ if you see errors wile compiling issue the repository and warnings
1. if compiled successfully and outputs wrong numbers than you using advanced calculations not basic it will always occor in many microcontroller not in QEMU emulator
2.many slow microcontroller executes slowly and the results will come longer not in qemu
3.if you want to use custom microcontroller or others use configure script to specify the device addreses by manually if you entered wrong number it will not execute or output
